# Metrics Shortlist

## Принцип

Главные метрики для `AI-Native Core` должны быть про бизнес-эффект, а не про “сколько раз люди открыли чат”.

## 1. Business effect metrics

- throughput per FTE;
- cycle time reduction;
- gross margin protection;
- cost to serve;
- speed of client response;
- conversion or win-rate uplift;
- avoided hiring;
- quality improvement with same headcount.

## 2. Operational metrics

- time to first draft;
- time to reviewed output;
- rework rate;
- acceptance rate;
- escalation rate;
- incident count;
- SLA adherence.

## 3. Adoption metrics

- active users in target role;
- repeat usage in real workflow;
- manager acceptance;
- champion activity;
- share of work done through new contour.

## 4. Quality metrics

- output completeness;
- factual correctness against SoT;
- formatting compliance;
- policy violations;
- unsafe action attempts;
- rollback frequency.

## Rule of thumb

Если проект показывает usage, но не показывает business effect, это ещё не AI-native core transformation. Это просто активность.
