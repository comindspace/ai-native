# Baseline Template

## Цель

До запуска пилота зафиксировать отправную точку, иначе потом нельзя будет честно показать эффект.

## 1. Scenario

- `Scenario / process`
- `Business unit`
- `Owner`
- `Measured period`

## 2. Current workflow

- как процесс выполняется сейчас;
- какие роли участвуют;
- сколько ручных шагов;
- где чаще всего возникают потери времени или ошибки.

## 3. Baseline business metrics

- throughput per week / month;
- average cycle time;
- cost to serve;
- volume per FTE;
- SLA attainment;
- current quality level.

## 4. Baseline operational metrics

- time to first draft;
- time to reviewed result;
- rework rate;
- clarification count;
- escalation count;
- incidents.

## 5. Baseline adoption reality

Если уже есть попытки использования AI:

- кто использует;
- как часто;
- для каких задач;
- насколько это встроено в реальный workflow.

## 6. Data quality notes

- откуда берутся baseline numbers;
- где данные надёжны;
- где есть ручные оценки;
- какие ограничения важно проговорить заранее.

## 7. Rule

Baseline должен быть достаточно точным для сравнения, но не обязан быть математически идеальным. Хуже всего не imperfect baseline, а его отсутствие.
