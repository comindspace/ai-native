# Pilot Design Mode

Используй этот режим, когда discovery уже пройдено и нужно превратить первую волну в управляемый пилот.

## Цель режима

Описать навыки, собрать pilot scope и провести его через quality layer.

## Порядок

1. [SKILL-template.md](../starter-kit/03-skills/SKILL-template.md)
2. [skill-spec-template.md](../starter-kit/03-skills/skill-spec-template.md)
3. [pilot-brief-template.md](../starter-kit/05-delivery/pilot-brief-template.md)
4. [release-gates.md](../starter-kit/04-quality/release-gates.md)
5. [eval-plan-template.md](../starter-kit/04-quality/eval-plan-template.md)

## Ожидаемый результат

- описаны `3-5` навыков первой волны;
- понятны owners и reviewers;
- pilot scope ограничен;
- есть gate logic;
- есть eval plan.

## Не делай здесь

- не запускай пилот без baseline;
- не бери новые роли, если ещё не собрана первая волна.
