## 1. Бизнес-контекст и цели

- [ ] Расскажите о вашей компании и бизнесе?
- [ ] Какую проблему хотите решить? Почему это важно сейчас?
- [ ] Какие цели проекта? Как будете измерять успех?
- [ ] Кто будет пользоваться системой? Сколько пользователей?
- [ ] Какой бизнес-эффект ожидаете? (экономия, рост выручки, скорость)

## 2. Текущее решение и боли

- [ ] Как сейчас решаете эту задачу?
- [ ] Что не устраивает в текущем решении?
- [ ] Какие системы уже используете? (CRM, ERP, Excel, ...)
- [ ] Были ли попытки решить раньше? Что не получилось?

## 3. Технические требования

- [ ] Есть ли ТЗ или описание требований?
- [ ] С какими системами нужна интеграция?
- [ ] Есть ли требования к инфраструктуре? (облако / on-premise)
- [ ] Требования к безопасности и данным?
- [ ] Какие данные есть? В каком формате и объёме?

## 4. Ограничения

- [ ] Какой бюджет заложен на проект?
- [ ] К какому сроку нужно запуститься? Почему этот срок?
- [ ] Есть ли ограничения по технологиям?
- [ ] Кто будет поддерживать систему после запуска?

## 5. Процесс принятия решения

- [ ] Кто принимает решение о старте проекта?
- [ ] Какой процесс согласования? Сколько времени занимает?
- [ ] С кем ещё рассматриваете сотрудничество?
- [ ] Что для вас важнее: цена / сроки / качество / экспертиза?

## 6. Следующие шаги

- [ ] Что нужно от нас для принятия решения?
- [ ] Когда удобно обсудить КП?
