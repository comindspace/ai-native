## Pre-Release (за 1 неделю)

### Code Freeze

- [ ] Все фичи milestone завершены
- [ ] Feature branches смержены в develop/main
- [ ] Code freeze объявлен команде
- [ ] Только багфиксы принимаются

### Задачи

- [ ] Все задачи milestone в статусе Done или Won't Fix
- [ ] Нет Critical/Blocker багов
- [ ] Все High-приоритетные баги исправлены
- [ ] Backlog просмотрен, отложенное задокументировано

---

## QA Gate (за 3-5 дней)

### Автоматические тесты

- [ ] Unit-тесты проходят (coverage ≥ 80%)
- [ ] Интеграционные тесты проходят
- [ ] E2E тесты проходят
- [ ] Performance тесты в норме

### Ручное тестирование

- [ ] Регрессионное тестирование завершено
- [ ] Критичные user flows проверены:
  - [ ] [Flow 1: описание]
  - [ ] [Flow 2: описание]
  - [ ] [Flow 3: описание]
- [ ] Кросс-браузерное тестирование (Chrome, Firefox, Safari)
- [ ] Мобильная версия проверена

|---------|----------|-------|
| Test Pass Rate | __% | ≥ 95% |
| Critical Bugs | __ | 0 |
| High Bugs | __ | ≤ 3 |
| Medium Bugs | __ | ≤ 10 |

## Documentation (за 2-3 дня)

- [ ] Release Notes подготовлены
- [ ] API документация обновлена
- [ ] User guide обновлён (если нужно)
- [ ] Runbook обновлён
- [ ] Changelog обновлён

---

## Infrastructure (за 1-2 дня)

### Staging

- [ ] Деплой на staging успешен
- [ ] Smoke-тесты на staging пройдены
- [ ] Клиент провёл UAT на staging (если нужно)

### Production Preparation

- [ ] Backup базы данных создан
- [ ] Rollback план подготовлен
- [ ] Мониторинг настроен
- [ ] Алерты проверены
- [ ] On-call инженер назначен

---

## Release Day

### Перед деплоем

- [ ] Команда уведомлена о релизе
- [ ] Клиент уведомлён (если нужно)
- [ ] Maintenance window согласован (если нужен)

### Деплой

- [ ] База данных мигрирована
- [ ] Приложение задеплоено
- [ ] Smoke-тесты на production пройдены:
  - [ ] Главная страница загружается
  - [ ] Авторизация работает
  - [ ] [Критичный flow 1] работает
  - [ ] [Критичный flow 2] работает

### После деплоя

- [ ] Мониторинг проверен (нет аномалий)
- [ ] Логи проверены (нет ошибок)
- [ ] Performance в норме

---

## Post-Release (1-2 дня после)

- [ ] Мониторинг 24 часа — нет проблем
- [ ] Мониторинг 48 часов — нет проблем
- [ ] Release Notes отправлены клиенту
- [ ] Ретроспектива релиза проведена
- [ ] Задачи milestone закрыты в Tracker

---

## Rollback Plan

### Условия для rollback

- Critical баг на production
- Потеря данных
- Недоступность сервиса > 15 минут

### Шаги rollback

1. [ ] Уведомить команду в Telegram
2. [ ] Откатить приложение: `[команда]`
3. [ ] Откатить миграции (если нужно): `[команда]`
4. [ ] Проверить smoke-тесты
5. [ ] Уведомить клиента
6. [ ] Создать post-mortem
