# Pilot Execution Mode

Используй этот режим, когда пилот уже запущен или всё готово к запуску.

## Цель режима

Показать эффект, удержать quality discipline и подготовить executive decision.

1. [metrics-shortlist.md](../starter-kit/07-metrics/metrics-shortlist.md)
2. [baseline-template.md](../starter-kit/07-metrics/baseline-template.md)
3. [stakeholder-map-template.md](../starter-kit/06-adoption/stakeholder-map-template.md)
4. [champion-model.md](../starter-kit/06-adoption/champion-model.md)
5. [pilot-communication-template.md](../starter-kit/06-adoption/pilot-communication-template.md)

9. [before-after-template.md](../starter-kit/07-metrics/before-after-template.md)
10. [executive-review-template.md](../starter-kit/05-delivery/executive-review-template.md)

## Ожидаемый результат

- baseline зафиксирован;
- adoption layer работает;
- weekly review идёт по ритму;
- есть scorecard;
- можно собрать before/after;
- руководству есть на что опираться в решении о следующей волне.

## Не делай здесь

- не подменяй business effect метриками использования;
- не масштабируй волну без executive review.
