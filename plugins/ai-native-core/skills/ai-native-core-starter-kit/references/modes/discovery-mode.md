# Discovery Mode

Используй этот режим, когда проект ещё только входит в `AI-Native Core`, но workshop or sponsor intent уже есть.

## Цель режима

Понять, что именно внедряем и с чего разумно стартовать.

## Порядок

1. [client-intake-template.md](../starter-kit/05-delivery/client-intake-template.md)
2. [operating-model.md](../starter-kit/01-positioning/operating-model.md)
3. [delegate-review-own.md](../starter-kit/01-positioning/delegate-review-own.md)
4. [decision-rights.md](../starter-kit/01-positioning/decision-rights.md)
5. [source-of-truth-map.md](../starter-kit/02-source-of-truth/source-of-truth-map.md)
6. [role-card-template.md](../starter-kit/03-skills/role-card-template.md)

## Ожидаемый результат

- понятен sponsor intent;
- понятны бизнес-цели;
- есть draft operating model;
- есть `Source of Truth`;
- выбраны `2-3` роли первой волны.

## Не делай здесь

- не переходи к детальным skill specs;
- не обещай пилот до SoT и role shortlist.
