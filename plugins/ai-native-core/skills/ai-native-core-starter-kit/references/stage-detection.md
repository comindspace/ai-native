# Stage Detection

Определи стадию проекта до того, как давать рекомендации.

## 1. Pre-discovery

Признаки:

- клиент ещё не проходил воркшоп;
- нет sponsor intent;
- нет понимания, зачем нужен `AI-Native Core`;
- запрос звучит как “посмотреть, что можно сделать с AI”.

Следующий шаг:

- workshop or diagnostic, не `Starter Kit`.

## 2. Discovery

Признаки:

- воркшоп уже был или есть явный sponsor intent;
- нужно понять, с чего стартовать;
- нужно зафиксировать business goals, role scope, SoT и первую волну.

Следующий шаг:

- intake -> operating model -> source of truth -> role cards.

## 3. Pilot Design

Признаки:

- роли первой волны уже понятны;
- нужно описать навыки, pilot scope, release gates;
- обсуждаются reviewers, quality criteria, decision mode.

Следующий шаг:

- skill specs -> pilot brief -> release gates -> eval plan.

## 4. Pilot Execution

Признаки:

- пилот уже запущен или всё готово к запуску;
- обсуждаются baseline, adoption, weekly review, before/after;
- нужен executive rhythm.

Следующий шаг:

- baseline -> adoption layer -> weekly review -> before/after -> executive review.

## 5. Review and Scale

Признаки:

- первая волна уже дала сигналы эффекта;
- обсуждается перенос на новые роли, процессы или бизнес-единицы.

Следующий шаг:

- executive review -> решение о масштабировании -> следующая волна.
