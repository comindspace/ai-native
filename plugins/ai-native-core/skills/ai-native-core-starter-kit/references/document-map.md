# Document Map

Используй эту карту, чтобы быстро направлять к нужным документам `Starter Kit`.

## Быстрые переходы

| Ситуация | Что открыть |
|---|---|
| Нужно понять общий маршрут | [HOW-TO.md](./starter-kit/HOW-TO.md) |
| Нужно стартовать проект | [client-intake-template.md](./starter-kit/05-delivery/client-intake-template.md) |
| Нужно зафиксировать operating model | [operating-model.md](./starter-kit/01-positioning/operating-model.md), [delegate-review-own.md](./starter-kit/01-positioning/delegate-review-own.md), [decision-rights.md](./starter-kit/01-positioning/decision-rights.md) |
| Нужно собрать `Source of Truth` | [source-of-truth-map.md](./starter-kit/02-source-of-truth/source-of-truth-map.md) |
| Нужно выбрать роли первой волны | [role-card-template.md](./starter-kit/03-skills/role-card-template.md) |
| Нужно описать навыки | [SKILL-template.md](./starter-kit/03-skills/SKILL-template.md), [skill-spec-template.md](./starter-kit/03-skills/skill-spec-template.md) |
| Нужно собрать пилот | [pilot-brief-template.md](./starter-kit/05-delivery/pilot-brief-template.md), [release-gates.md](./starter-kit/04-quality/release-gates.md), [eval-plan-template.md](./starter-kit/04-quality/eval-plan-template.md) |
| Нужно снять baseline | [metrics-shortlist.md](./starter-kit/07-metrics/metrics-shortlist.md), [baseline-template.md](./starter-kit/07-metrics/baseline-template.md) |
| Нужно собрать adoption layer | [stakeholder-map-template.md](./starter-kit/06-adoption/stakeholder-map-template.md), [champion-model.md](./starter-kit/06-adoption/champion-model.md), [pilot-communication-template.md](./starter-kit/06-adoption/pilot-communication-template.md), [training-plan-template.md](./starter-kit/06-adoption/training-plan-template.md) |
| Нужно вести weekly review | [weekly-review-agenda.md](./starter-kit/05-delivery/weekly-review-agenda.md), [pilot-scorecard.md](./starter-kit/04-quality/pilot-scorecard.md) |
| Нужно показать эффект | [before-after-template.md](./starter-kit/07-metrics/before-after-template.md), [executive-review-template.md](./starter-kit/05-delivery/executive-review-template.md) |

## Правило

Если пользователю нужен “следующий шаг”, почти всегда достаточно направить его к 1-3 документам, а не перечислять весь Starter Kit.
