# Champion Model

## Зачем нужны champions

`AI-Native Core` не масштабируется только через sponsor и delivery team.

Нужны внутренние champions, которые:

- помогают переводить язык программы на язык роли;
- показывают first wins;
- снижают страх перед новым контуром;
- помогают ловить friction раньше, чем он превращается в саботаж.

## Кто подходит на роль champion

- у человека есть доверие внутри команды;
- он реально понимает работу роли, а не только “поддерживает инновации”;
- он готов тратить время на обратную связь;
- он не воспринимается как “контрольная функция сверху”.

## Роль champion

- тестировать первые сценарии;
- давать обратную связь по реальному workflow;
- помогать объяснять коллегам, как и зачем меняется работа;
- помогать менеджеру отделять полезные сигналы от шума;
- подсвечивать сопротивление и hidden blockers.

## Что champion не должен делать

- заменять process owner;
- в одиночку “тащить внедрение”;
- быть единственным каналом обучения;
- отвечать за политические конфликты между подразделениями.

## Minimum champion setup

Для первой волны достаточно:

- `1` sponsor;
- `1` process owner на каждый ключевой процесс;
- `1` champion на каждую целевую группу пользователей.

## What champions need from us

- понятный narrative;
- короткие материалы для команды;
- быстрый канал эскалации;
- понятные правила пилота;
- регулярный ритм обратной связи.
