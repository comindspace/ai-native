# Executive Review Template

## 1. Current status

- какой этап программы идёт сейчас;
- что уже собрано;
- что ещё не готово;
- где есть блокеры.

## 2. Business effect summary

- какие первые сигналы эффекта уже видны;
- где сокращается cycle time;
- где снижается ручная нагрузка;
- где есть потенциал роста пропускной способности.

## 3. Pilot and rollout summary

- какие пилоты запущены;
- какие роли участвуют;
- какой статус по `Delegate / Review / Own`;
- какие сценарии готовы к следующему шагу.

## 4. Risks

- риски по данным;
- риски по ownership;
- риски по adoption;
- риски по quality;
- риски по scope creep.

## 5. Decisions needed from leadership

- что нужно утвердить;
- какие границы и приоритеты надо закрепить;
- где нужен sponsor intervention;
- где нужен выбор между скоростью и качеством.

## 6. Next wave recommendation

- какие процессы брать следующими;
- какие не стоит включать пока;
- что нужно подготовить до расширения.

## 7. Leadership message

Короткая рамка для руководства:

- зачем продолжаем;
- что уже доказано;
- что ещё нельзя обещать;
- на чём держим дисциплину внедрения.
