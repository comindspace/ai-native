# ai-native: платформа скиллов для агентов

[Read in English](README.md)

Портативная система скиллов для ИИ-ассистентов. Скилл — исполняемая инструкция: как выполнять работу по правилам компании. Скиллы живут в репозитории, версионируются, проходят ревью и собираются в устанавливаемые паки для разных агентов: Claude Code, Codex, Cursor, OpenCode, OpenClaw, Hermes, ZCode.

Здесь лежит референсный набор AI-Native: методологические скиллы для операционной модели «человек плюс ассистент», контракт скилла и сборщик паков.

Контракт: `SKILL.md` (инструкция) + `skill.yaml` (манифест: версия, совместимые агенты, требования) + опциональные `references/`, `scripts/`, `assets/`, `evals/`. Каждый упакованный скилл несёт телеметрический контракт `gateway-skill-telemetry:v1`: агент отмечает запуск и завершение скилла, в телеметрию не попадают промпты, тексты документов и секреты.

Сборка паков:

```bash
python agent-platform/build_agent_plugins.py validate-skills
python agent-platform/build_agent_plugins.py build-plugins --clean
```

Доступ агентов к корпоративным системам — через один MCP-шлюз [`comindspace/gateway-mcp`](https://github.com/comindspace/gateway-mcp): OAuth, права на действия и ресурсы, аудит, изоляция секретов.

Лицензия — Apache-2.0.
