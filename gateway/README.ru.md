# GatewayMCP

[Read this in English](README.md)

GatewayMCP — единая MCP-граница между агентными ассистентами (Claude Code, Codex, Cursor, OpenCode, OpenClaw, Hermes и любой MCP-клиент) и внешними системами: вики, трекер, хостинг кода, CRM, мессенджеры, почта, календарь, облачные диски, аналитика.

Ассистенты аутентифицируются один раз и зовут небольшой стабильный набор публичных MCP-инструментов. Креды бэкендов, правила доступа, аудит и корпоративная память остаются внутри шлюза и его Postgres. Агенты никогда не получают токены внешних систем.

Ключевое:

- один вход для всех агентов и всех систем;
- скоупы плюс персональные гранты на ресурсы (проект, очередь, документ, чат), отказ сильнее разрешения;
- пер-юзерные креды шифруются, серверные токены по умолчанию выключены;
- каждый вызов инструмента пишется в аудит;
- санитизированные производные слои: контекст компании, процессная аналитика, память.

Быстрый старт: `cp deploy.env.example .env`, заполнить переменные, `docker compose up -d`, проверить `http://localhost:8000/healthz`, подключить MCP-клиент к `/mcp`.

Подробности: архитектура и модели доступа — в [README.md](README.md) и `docs/architecture.md`; правила контрибуции — в [CONTRIBUTING.md](CONTRIBUTING.md). Лицензия — Apache-2.0.

Скиллы для ассистентов и сборщик плагин-паков — в репозитории [`comindspace/ai-native`](https://github.com/comindspace/ai-native).
